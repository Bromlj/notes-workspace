NOTES WORKSPACE · 4.1.0

Your notepad. A panel when you need it.

Write ordinary notes. Alt+W opens the Reference panel in the same window; Alt+Q immediately hides it. Replies come directly from your signed-in Codex account.

Getting started

Use the Notes Workspace desktop shortcut to start the local connector and open the notepad. Codex must be installed and signed in with ChatGPT.

Press Alt+W, type in the question box and press Enter. Choose a model and thinking level under Options. Attach documents or drop them onto the panel. The main note is never sent automatically.

Formatting buttons visibly format the note. File → Save as creates plain text; Save formatted HTML preserves the styling. Recovery saves retain formatting.

This uses your Codex allowance. Your normal ChatGPT browser remains independent; no ChatGPT webpage is opened underneath this editor.

Shortcuts

Shortcuts work while the browser/app has focus. Native file dialogs and Windows controls can take priority. Repeating Alt+Q never reveals the panel.

Preferences

Optional restore passphrase

Require a passphrase after Alt+W. This prevents accidental revealing; it does not encrypt notes or secure an unlocked computer.

Projects and Codex tools

In the panel, choose Options, paste an existing project folder path and press Use folder. Codex can read and edit that project, run commands and tests, and use its configured skills and tools. Additional access requests appear inside the panel for your decision. A new folder starts a new conversation.

An accepted task continues while hidden. Approval prompts wait for you to reopen the panel. Stop interrupts work. Send becomes Steer during a task so you can add instructions. Activity shows commands and file changes; Options provides saved conversations, review and context compaction.

Connection and storage

A failed request is never automatically resent. Reconnect refreshes the available models and connection.

Notes and transcripts are saved locally in this extension's existing browser profile. Codex also keeps its conversation history in its usual local storage. The ordinary note is not automatically added to a prompt. Submitted questions, attachments and content read by Codex tools are processed under your Codex account and tool settings. No API key is needed.

The panel uses the installed Codex agent runtime. Some desktop-specific interfaces, integrations and media controls are not exposed here. Text extraction supports text documents, PDFs and modern Office documents; scanned PDFs need OCR or page images. This is visual privacy, not concealment from system inspection or screen recording.
